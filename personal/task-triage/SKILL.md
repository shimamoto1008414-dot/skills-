# Task Triage(タスク整理)

思いついた順の雑多なタスクを、緊急度×所要時間で整理して「次に何をやるか」を
即決できる形にするワークフロー。仕事と大学院を両立している前提なので、
**隙間時間に消化できる短タスク**と**ブロック確保が必要な長タスク**の分離を最優先する。

## Step 0: 入力

入力は雑でよい(思いついた順・断片・箇条書きでなくても可)。以下も入力にできる:

- advisor-meeting-logger / meeting-record-keeper の記録の貼り付け
  → 「TODO」「宿題事項」セクションを拾う。ただし**担当が「先方」のものは
  自分のタスクに入れず「待ち」リストへ**回す
- 「あれもやらなきゃ」のような口頭列挙 → 1 件ずつタスクに起こす

期限・所要時間が不明なら文脈から推定して「(推定)」と付け、確認質問でブロックしない。
判断できないものだけ「判断が必要」リストに隔離する。

## Step 1: 分類(統制語彙)

各タスクに 3 つのタグを付ける:

- **カテゴリ**: 仕事 / 大学院 / 私用
- **緊急度**: 至急(今日中) / 今週 / それ以降・期限なし
- **所要時間**: 短(〜15分) / 中(〜1時間) / 長(1時間超)

分類の原則:

- **長タスクは必ず「最初の一手」に分割する。** 1時間超のタスクには
  「15〜30分でできる最初の一歩」を添える(例: 「報告書を書く」→
  最初の一手「目次だけ立てる」)。先延ばしは長タスクで起きる
- 締切がある場合は緊急度の判定根拠として期限(MM/DD)を必ず残す
- 「緊急だと本人が感じているだけで期限がないもの」は それ以降 に置いてよい。
  ただし勝手に降格せず「(期限なしのため)」と理由を添える

## Step 2: 出力(固定テンプレート・日本語)

```
# タスク整理(YYYY-MM-DD)
## 今すぐ片付ける(至急 × 短)
- [ ] タスク(カテゴリ / 〜15分)
## 今日ブロックを確保(至急 × 中・長)
- [ ] タスク(カテゴリ / 目安: ○分 / 最初の一手: 〜)
## 隙間時間に(急がない × 短)
- [ ] タスク(カテゴリ)
## 予定に組む(急がない × 中・長)
- [ ] タスク(カテゴリ / 期限: MM/DD / 最初の一手: 〜)
## 待ち(先方・返事待ち)
- 内容(誰待ち / いつから)← 自分のタスクではないが埋もれさせない
## 判断が必要
- 内容(何が決まれば動けるか)
```

出力の最後に「今日はまずこれ」を 1〜3 件だけ推薦する(全部はやれない前提で選ぶ)。

## Step 3: 保存と Notion 連携

- **基本はチャットで完結する**(思いついたら投げる→整理して返す)。
  保存しなくても毎回作り直せるのがこのスキルの前提
- Notion MCP 接続時のみ、出力後に「分類済みタスクを DB に登録しますか?」と
  一度だけ提案する。無断でページを作成しない
- タスク用 DB がまだ無い場合は、`references/notion_db_schema.md` のスキーマで
  **新しい DB を 1 個だけ作る**ことを提案する。既存の散らかったページ・DB は
  触らない・移行しない(必要になったタスクだけ都度移す)
