# 検索ガイド(論文・図書)

## 論文の検索先(この順で使う)

1. **CiNii Research** — 日本語論文の第一候補。書誌の正本として使う
2. **J-STAGE** — 日本語のオープンアクセス本文。PDF リンクをそのまま渡せる
3. **Google Scholar** — 英語文献と被引用数。重要文献は「引用元」で芋づる検索
4. **大阪大学学術情報庫 OUKA** — 阪大リポジトリ。紀要・学位論文
5. 阪大契約データベース(学内ネットワーク限定のもの)— 上で見つからないときに
   「学内からアクセスして確認」と案内する(学外からの代理取得はしない)

## 検索語の設計

- 必ず日英両方を作る(例: 「プライバシー 概念」 / "privacy concept theory")
- 概念整理型の課題では、「レビュー」「展望」「動向」/ "review" を付けた検索を
  必ず 1 回入れる(レビュー論文が最短の入口)
- 検索語は 2〜3 語 × 3 パターンまでで始める(発散防止)。ヒットが偏ったら
  同義語(例: 個人情報 / personal information、監視 / surveillance)で 1 回だけ広げる
- 検索したパターンと件数感を成果物に一言残す(「何で探したか」が再現できるように)

## 大阪大学 OPAC(図書の所蔵検索)

- URL: https://opac.library.osaka-u.ac.jp/
  (開けない・変わっている場合は「大阪大学 図書館 OPAC」で Web 検索して入る)
- 読み取る項目: **所蔵館 / 配架場所 / 請求記号 / 状態(貸出中か)**
- 所蔵館とキャンパスの対応(必ず書く):
  - 総合図書館 = **豊中**
  - 生命科学図書館 = **吹田**
  - 理工学図書館 = **吹田**
  - 外国学図書館 = **箕面**
  - ※人間科学研究科は吹田キャンパス。豊中・箕面所蔵の本は移動か取り寄せが必要
- 電子ブックもヒットする。紙が貸出中のときは電子版の有無を必ず確認する
- 所蔵なし・全冊貸出中の場合: ILL(他館からの取り寄せ)・購入希望の制度がある。
  手続きの詳細は推測で書かず「図書館サイトの案内に従う」とだけ添える

## 報告の書式(文献 1 件あたり)

- **論文**: 著者(年)「タイトル」『誌名』巻(号), 頁範囲.
  [入手: J-STAGE 等のリンク or DOI] — なぜ読むか 1 行
- **本**: 著者『書名』出版社, 年.
  [所蔵: ○○図書館(キャンパス)/ 配架: ○○ / 請求記号: ○○ / 状態: 貸出可 など]
  — なぜ読むか 1 行
- リンク・所蔵情報は検索結果からコピーしたものだけを書く。埋められない欄は
  空欄にせず「要確認」と書く
