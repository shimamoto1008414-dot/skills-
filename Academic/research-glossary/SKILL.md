# Research Glossary(用語・概念の貯蔵庫)

出会った用語をその場の理解で終わらせず、毎回同じ形で貯めるワークフロー。
貯蔵庫の価値は「修論を書くとき・ゼミで説明を求められたときに、
自分の言葉の定義へすぐ戻れること」にある。

## Step 0: モード判定

- **登録モード(基本)** — 「この単語どういう意味?」と聞かれたら、
  まず分かりやすく説明し、**続けて必ず Step 2 の登録エントリ形式でも出力する**
  (依頼がなくても出す。cad-workflow-notes と同じ「二度調べない」方式)
- **一括取り込みモード** — academic-paper-translator の「重要用語 対訳集」表や
  授業ノート・単語メモを貼られたら、1 用語 1 エントリに変換する。
  件数が多いときは一言定義だけの簡易版でよい(あとで育てられる)
- **照会モード** — 「前に調べた〜」「〜って登録してたっけ」 → 過去エントリから探す。
  手元に無ければ Notion MCP 接続時は DB 検索を提案し、未接続なら
  用語集の貼り付けを一度だけ依頼する
- **復習モード** — 「復習したい」 → 貼られた(または DB の)エントリから、
  理解度「要復習」を優先して簡単な確認問題を出す(用語→意味、意味→用語の両方向。
  answering 後に正解のエントリを見せる)

## Step 1: エントリの原則

- **定義は自分の言葉で書く(1〜2 文)。** 辞書のコピペは覚えられない。
  ただし統計用語・法律用語など正確さが命の語は、正確な定義を優先し
  「かみ砕き」を併記する
- **不確かな定義を断定しない。** 訳語が揺れている・分野で意味が違う語は
  その旨を書き、「要確認」を付ける
- 用語名は「日本語訳 (原語)」形式で統一(literature-review-assistant と同じ規則。
  日英どちらで検索しても見つかるように)
- `references/research_context.md` を読み、自分の研究と関わる語には
  その関わりを一言添える(無理に関連づけない。関わらない語は空欄でよい)

## Step 2: エントリ形式(固定テンプレート・日本語)

Notion 貼り付け用に、プロパティ部と本文部の 2 部構成で出す。

### プロパティ部

| プロパティ | 値 |
|---|---|
| 用語 | 日本語訳 (原語)(例: 厚い記述 (thick description)) |
| 分野タグ | 下の統制語彙から 1 つ |
| 理解度 | 説明できる / なんとなく / 要復習 |
| 出典 | 出会った論文・授業(例: Pepper (2020) / 質的研究法の授業) |
| 追加日 | YYYY-MM-DD |

**分野タグ(統制語彙)**: プライバシー・監視 / 動物倫理・人と動物 /
研究方法(質的) / 研究方法(量的・統計) / 学術一般 / その他

### 本文部

```
## 一言定義
(自分の言葉で 1〜2 文。ここだけ読めば思い出せる粒度)
## 詳しい説明
(必要な語だけ。背景・由来・かみ砕いた説明)
## 使用例
(出会った文の短い引用(50字未満)や、自分の研究ならこう使う、の例文)
## 関連用語
(対になる語・混同しやすい語。貯蔵庫にある語なら「登録済み」と添える)
## 自分の研究との関わり
(あれば。動物のプライバシー研究のどこで効くか)
```

## Step 3: 保存と Notion 連携

1. まずエントリを**必ずチャットに出力する**(確認待ちで止めない)
2. Notion MCP 接続時のみ、出力後に「用語集 DB に登録しますか?」と一度だけ提案する。
   無断でページを作成しない
3. 用語集 DB がまだ無い場合は、`references/notion_db_schema.md` のスキーマで
   **新しい DB を 1 個だけ作る**ことを提案する(既存ページの整理は不要)

## 他スキルとの連携

- academic-paper-translator で翻訳した論文の対訳表 → 一括取り込みモードへ
- literature-review-assistant は「文献単位」、本スキルは「用語単位」。
  文献ノートのキーワード欄から気になる語だけ拾って登録してもよい
- ゼミで説明を求められそうな語は理解度を「要復習」にしておき、
  ゼミ前に復習モードで確認する
