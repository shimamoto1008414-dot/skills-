# 用語集 DB スキーマ(Notion)

**このファイルの役割**: Notion に用語集 DB を作る日が来たら、この定義通りに 1 個だけ
作る。Notion MCP 接続時に「このスキーマで用語集 DB を作って」と言えばそのまま作れる。
既存のページ・DB の整理は不要(新 DB を 1 個作るだけ)。

## DB 名

用語集

## プロパティ定義

| プロパティ | 型 | 選択肢(統制語彙・SKILL.md と完全一致させる) |
|---|---|---|
| 用語 | Title | 「日本語訳 (原語)」形式 |
| 分野タグ | Select | プライバシー・監視 / 動物倫理・人と動物 / 研究方法(質的) / 研究方法(量的・統計) / 学術一般 / その他 |
| 理解度 | Select | 説明できる / なんとなく / 要復習 |
| 出典 | Text | 出会った論文・授業 |
| 追加日 | Date | — |

ページ本文には SKILL.md の本文部テンプレート(一言定義/詳しい説明/使用例/
関連用語/自分の研究との関わり)をそのまま貼る。

## 推奨ビュー

1. **すべて(既定)**: 追加日の降順。用語集は完了が無いので全件表示でよい
2. **要復習**: 理解度 = 要復習(ゼミ・発表の前に見る)
3. **分野別**: 分野タグでグループ化(修論の章立てに合わせて眺める)

## 運用ルール

- 1 用語 1 ページ。同じ語を二重登録しそうなときは既存ページに追記する
- 理解度は育てる: 復習して説明できるようになったら「説明できる」に上げる
- 修論執筆が始まったら、「分野別」ビューがそのまま用語整理・定義節の下書き材料になる
