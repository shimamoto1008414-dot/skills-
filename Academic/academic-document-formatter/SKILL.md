# Academic Document Formatter

大学院の研究・ゼミ活動用の文書を、用途に応じて 4 種類に作り分けるスキル。
本ファイルは判定ロジックと共通ルールのみ。用途別の詳細ルールは `reference/` 配下に
分離してあるので、**該当する 1 ファイルだけを読み込む**こと(トークン節約のため、
使わない reference は読まない)。

## 1. 用途の判定

| 用途 | 出力フォーマット | 読み込む参照ファイル |
|---|---|---|
| ゼミ発表 | pptx | `reference/seminar.md` |
| 課題提出用レジュメ | docx | `reference/resume.md` |
| レポート(提出用) | docx | `reference/report.md` |
| 自分用メモ・下書き | docx(基本)または md | `reference/personal.md` |

判定の手がかり:
- 「ゼミ」「発表」「スライド」「発表資料」→ ゼミ発表(pptx)
- 「レジュメ」「課題」「提出」+授業名 → 課題レジュメ(docx)
- 「レポート」「期末」「提出用の文章」→ レポート(docx)
- 「メモ」「下書き」「自分用」「整理したい」→ 自分用メモ(基本は docx。明示指定があれば md)

**ユーザーが用途を明言していない場合は、推測で決め打ちせず、まず一言だけ確認する。**
(例:「これはゼミ発表用ですか、それとも課題提出用ですか?」)
用途が確定したら、対応する reference ファイルを読んでから作成に入る。

## 2. 共通の書式ルール

### 提出・発表用(seminar / resume / report 共通)
- docx の本文は **MS明朝 10.5pt**、pptx は **16:9・本文 18pt 以上**(詳細は各 reference)。
- 文字は**黒一色のみ**。強調は太字・フォントサイズ・階層で表現し、色文字は使わない。
- 装飾的な罫線・囲み線・背景色は使わない(表の必要最小限の罫線は可)。
- レイアウトはできるだけシンプルに。**余白と見出しの階層構造**で情報を整理する。

### 自分用(personal)
- 薄いグレーなど目立たない色で、注釈・コメントを本文と区別して入れてよい。
- 思考の途中経過・疑問点・TODO をそのまま残してよい。
- 体裁の厳密さより、後で見返せる自由度を優先する。

## 3. 他スキルとの連携・境界

- pptx 生成時は pptx スキル(`/mnt/skills/public/pptx/SKILL.md`)、docx 生成時は
  docx スキル(`/mnt/skills/public/docx/SKILL.md`)が利用可能ならそちらの作法に従う。
- **境界**: 文献を読む・訳す → `academic-paper-translator`。
  文献レビューを記録・蓄積する → `literature-review-assistant`。
  自分の発表資料・提出物・メモを作る → 本スキル。
