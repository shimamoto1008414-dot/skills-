# レポート(提出用・docx)の作成ルール

## 前提
- docx スキル(`/mnt/skills/public/docx/SKILL.md`)が利用可能な環境では、
  必ずそちらを読み込み、その作法に従って docx を生成する。

## レポートの型

1. **表紙情報**(独立した表紙ページが指定されていなければ、1 ページ目冒頭にまとめる)
   - タイトル / 授業名・担当教員名 / 氏名・学籍番号・所属 / 提出日
   - 学籍番号は **21A260022**(本人の学籍番号。氏名・所属は作成時に確認する)。
2. **序論** — 問題設定。何を論じるか、なぜ論じる価値があるかを示す。
   レポート全体の見取り図(本論で何をどの順に扱うか)を最後に一文入れる。
3. **本論** — 節に分けて論じる。1 節 1 論点。
   - 主張 → 根拠(文献・データ)→ 検討、の順を基本にする。
   - 引用と自分の意見の区別を明確にする。
4. **結論** — 序論の問いに答える形でまとめる。新しい論点は出さない。
5. **参考文献** — 末尾に一覧(下記「参考文献書式」に従う)。
   - 授業側に別の書式指定(APA など)がある場合はそちらを最優先する。

## 参考文献書式(太田貴大先生の論文書式)

太田先生の共著論文(平木・太田「日本における国内外来種研究の特徴と意義」
環境共生 Vol.41 No.1, 2025)の引用文献リストから抽出した書式。**引用順に番号を振る**
方式(著者名アルファベット順ではない)。本文・スライドともにこの書式で統一する。

### 本文中の引用
- 引用箇所の**右肩に番号**を付す。例:「…と定義される<sup>1), 2)</sup>.」
  「Roy et al.(2023)<sup>3)</sup>は…」
- 番号は本文に登場した順に 1) から振り、末尾の一覧の番号と対応させる。
- docx では上付き文字(superscript)、md では `<sup>1)</sup>` で表現する。

### 末尾の文献リスト(各行の書式)
番号は「1)」「2)」…と半角数字+半角丸括弧。要素の区切りは半角カンマ+スペース。

- **和文の学術論文**:
  `著者名(発行年): 論文名, 誌名, Vol.○, No.○, pp.始-終`
  例) `村上興正(2000): 日本における外来種の法的規制, 保全生態学研究, Vol.5, No.2, pp.119-130`
- **著者が複数(和文)**: 姓名の間は中黒「・」でつなぐ。
  例) `上井達矢・更科美帆・吉田剛司(2015): …, 酪農学園大学紀要 自然科学編, Vol.40, No.1, pp.29-33`
- **書籍(単著・編著)**:
  `著者/編者名(発行年): 書名, 出版社`
  例) `日本生態学会編(2002): 外来種ハンドブック, 地人書館`
- **書籍の一章**:
  `著者名(発行年): 章タイトル, 書名, pp.始-終, 出版社`
  例) `瀬野宏(2013): 国内外来魚とは何か, 見えない脅威"国内外来魚"どう守る地域の生物多様性, pp.3-18, 東海大学出版`
- **学位論文**:
  `著者名(発行年): 論文タイトル, 博士論文/修士論文, 大学名`
  例) `沖野友祐(2023): 日本のタカハヤの遺伝的集団構造と…, 博士論文, 愛媛大学大学院`
- **英語文献**(和文論文中に混在する場合も同じ番号列に入れる):
  `Surname, Initials., ... and Surname, Initials.(発行年): Title, Journal, Vol.○, No.○, pp.始-終`
  例) `Nelufule, T., Robertson, M. P., Wilson, J. R. U. and Faulkner, K. T.(2022): Native-alien Populations…, NeoBiota, Vol.74, pp.57-74`
- **ウェブ資料(官公庁 HP 等)**:
  `機関名 HP(発行年。不明なら「不明」): ページ名, URL, 参照 YYYY-MM-DD`
  例) `環境省 HP(2015): 生態系被害防止外来種リスト, https://www.env.go.jp/…, 参照 2024-06-30`

### 書式上の注意
- 発行年の直後は必ず**コロン「:」**(和文の丸括弧年でも同じ)。
- 巻・号・頁は `Vol.` `No.` `pp.` を用いる(号のみ/頁のみの資料はある分だけ書く)。
- ウェブ資料には必ず「参照 年月日」を付す。
- 上記 3 論文のうち英文誌掲載分(Frontiers / Elsevier)は各誌のハウススタイルに
  従っており、日本語提出物ではこの環境共生誌の書式を採用する。

## 体裁ルール
- 本文フォントは **MS明朝 10.5pt**。見出しは MSゴシック太字(サイズは本文+1〜2pt)。
- `reference/resume.md` と同じ体裁ルールを適用する:
  黒一色のみ / 罫線・囲み線・背景色なし / 見出しは太字+サイズ差のみ /
  余白と階層構造で整理。
- 分量指定(字数・ページ数)がある場合は最優先で守る。
- ページ番号を下部中央に入れる(表紙を除く指定があればそれに従う)。
