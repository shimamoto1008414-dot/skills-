# レポート(提出用・docx)の作成ルール

## 前提
- docx スキル(`/mnt/skills/public/docx/SKILL.md`)が利用可能な環境では、
  必ずそちらを読み込み、その作法に従って docx を生成する。

## レポートの型

1. **表紙情報**(独立した表紙ページが指定されていなければ、1 ページ目冒頭にまとめる)
   - タイトル / 授業名・担当教員名 / 氏名・学籍番号・所属 / 提出日
2. **序論** — 問題設定。何を論じるか、なぜ論じる価値があるかを示す。
   レポート全体の見取り図(本論で何をどの順に扱うか)を最後に一文入れる。
3. **本論** — 節に分けて論じる。1 節 1 論点。
   - 主張 → 根拠(文献・データ)→ 検討、の順を基本にする。
   - 引用と自分の意見の区別を明確にする。
4. **結論** — 序論の問いに答える形でまとめる。新しい論点は出さない。
5. **参考文献** — 末尾に一覧。
   - 書式は**太田貴大先生の論文の参考文献書式に合わせる**。
     <!-- TODO: 太田先生の論文ファイルを受け取ったら、文献リストの実例から
          書式ルール(和文献・英文献・論文・書籍・ウェブ資料の各形式と
          本文中の参照形式)を抽出してここに具体的に記載する -->
   - 書式詳細が未記載の間の暫定形: 和文献は「著者名(出版年)『書名』出版社」、
     論文は「著者名(出版年)「論文名」『掲載誌名』巻号, 頁」、
     本文中の参照は「(著者名 出版年: 頁)」とし、作成時にユーザーへ
     「太田先生書式の詳細が未登録のため暫定書式で作成した」ことを一言伝える。
   - 授業側に別の書式指定がある場合はそちらを最優先する。

## 体裁ルール
- 本文フォントは **MS明朝 10.5pt**。見出しは MSゴシック太字(サイズは本文+1〜2pt)。
- `reference/resume.md` と同じ体裁ルールを適用する:
  黒一色のみ / 罫線・囲み線・背景色なし / 見出しは太字+サイズ差のみ /
  余白と階層構造で整理。
- 分量指定(字数・ページ数)がある場合は最優先で守る。
- ページ番号を下部中央に入れる(表紙を除く指定があればそれに従う)。
