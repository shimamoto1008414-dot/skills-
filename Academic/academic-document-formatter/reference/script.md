# 原稿(発表で読み上げる台本・docx/md)の作成ルール

スライド発表やレジュメ報告のときに、手元で読み上げる/カンペにする「発表原稿」を作る
様式。**基本的に自分用**(配布・提出しない)なので、体裁の厳密さより
「読み上げやすさ・時間管理」を優先する。

## 前提
- フォーマットは **docx を基本**とする。ユーザーが md を明示指定した場合のみ md にする。
- docx スキル(`/mnt/skills/public/docx/SKILL.md`)が利用可能なら、その作法に従う。
- 配布・提出しないので、黒一色などの提出用ルールは必須ではない
  (ト書き・注釈はグレーや「※」で本文と区別してよい)。

## 原稿の型

1. **冒頭に発表情報**(何の発表の原稿か)— 日付・発表の場・発表タイトル・想定発表時間。
2. **対応づけ** — スライド発表ならスライド番号、レジュメ報告なら見出しと対応させ、
   「どこを話しているか」が原稿上で分かるようにする(例:「【スライド3:問い】」)。
3. **本文(話し言葉)** — 実際に口に出す言葉をそのまま書く。
   - 一文を短く。読点で息継ぎできる長さにする。
   - 専門用語には言い換え・補足を口頭で添える前提で書く。
   - つなぎ(「まず」「次に」「まとめると」)を入れて展開を追いやすくする。
4. **ト書き・指示**(本文と区別して挿入)— 間の取り方、強調、図を指すタイミング、
   質疑への布石など。グレー文字や「※」「(→図2を指す)」のように地の文と分ける。
5. **区切り** — パートごとに空行・見出しを入れ、パート冒頭に**尺の目安**を書く
   (例:「(ここまで約2分)」)。

## 分量・時間の目安
- 日本語の読み上げは **300〜350字/分** が目安。発表時間から逆算して総字数を決める。
  - 例:5分の発表 → 約1,500〜1,750字。10分 → 約3,000〜3,500字。
- 各パートにも時間を割り振り、超過しそうな箇所は削る候補に印を付けておく。

## 体裁ルール
- 本文は読み上げやすいよう**行間広め**(1.5 程度)、パートの区切りで改行・空行を入れる。
- docx の場合:本文は MS明朝、ト書き・注釈はグレー(例: RGB 128,128,128)で区別してよい。
- md の場合:ト書きは引用ブロック(`>`)や「※」始まりの行など一貫した記法で区別する。

## 他様式との関係
- 原稿は**スライド/レジュメとセットで作る**ことが多い。元になる資料があれば、その構成
  (見出し・スライド順)に沿って原稿を組み立てる。
- 発表本番用に配布・投影する資料は、原稿とは別に slide / resume のルールで作る。
