# 自分用メモ・下書きの作成ルール

## 前提
- フォーマットは docx または md。ユーザーの指定がなければ md を基本とし、
  Word で開いて追記したい様子があれば docx にする。
- 提出物ではないので、体裁の厳密さより**後で見返したときに思考プロセスを
  追えること**を最優先する。

## 書き方の方針

- 思考の途中経過をそのまま残してよい。結論が出ていない論点は
  「未解決」「要検討」と明示して残す。
- 疑問点・違和感・思いつきは消さずに記録する。後の研究の種になる。
- 構成は自由。ただし最低限、日付と主題(何についてのメモか)を冒頭に書く。
- 関連する文献・授業・ゼミ回への言及があれば書き添える
  (「〇〇先生のコメント」「△△(2023)を読んで」など)。

## 注釈・コメントの色ルール

- 本文と注釈を視覚的に区別するため、注釈側に薄いグレーなど目立たない色を使ってよい
  (提出・発表用の黒一色ルールは適用しない)。
- docx の場合: 注釈・自分ツッコミはグレー(例: RGB 128,128,128)の文字色、
  またはコメント機能で入れる。
- md の場合: 色は使えないので、引用ブロック(`>`)や `<!-- -->`、
  「※」始まりの行など、一貫した記法で注釈を区別する。
- どの記法・色を使ったかは文書内で一貫させる(後で見返すときの手がかりになるため)。

## 下書きから提出物への昇格

このメモを元に後日レジュメ・レポート・発表資料を作る場合は、
該当する reference(resume / report / seminar)のルールに沿って作り直し、
グレー注釈・未整理の思考は本文から取り除く(必要なら別メモとして残す)。
