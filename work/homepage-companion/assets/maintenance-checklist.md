# ホームページ保守チェックリスト

サイトを健康に保つための点検リストです。完璧を目指さなくて大丈夫。「月1回ちょっと見る」くらいの気持ちで続けるのが、いちばん効きます。カレンダーに「サイトの点検日」を入れておくのがおすすめです。

---

## 毎月（5〜10分）

- [ ] WordPress本体・テーマ・プラグインに「更新あり」の通知がないか確認 → あれば更新
  - ※ 更新の前に、まずバックアップ
  - ※ 更新後、サイトを開いて見た目が崩れていないか確認
- [ ] バックアップがちゃんと取れているか確認（自動設定していても、たまに確認）
- [ ] 営業時間・定休日・料金・お知らせなど、情報が古くなっていないか
- [ ] （余力があれば）お知らせ・ブログを1本

## 半年に1回（じっくり）

- [ ] 全ページを **スマホ** で見て、崩れ・読みにくさがないか
- [ ] 全ページを **パソコン** でも確認
- [ ] メニューやボタンのリンク切れがないか（全部押してみる）
- [ ] 問い合わせフォームにテスト送信して、ちゃんと届くか
- [ ] 使っていないプラグイン・テーマを削除
- [ ] 写真が重くてサイトが遅くなっていないか

## 随時（変化があったとき）

- [ ] 営業情報が変わった → すぐ更新
- [ ] キャンペーン・新メニュー → お知らせを出す
- [ ] 大きな変更をする前 → 必ず手動バックアップ

## 安全のための習慣

- [ ] ログインのパスワードは強く、使い回さない
- [ ] 管理画面のユーザー名・パスワードを安全に保管している
- [ ] 知らないメールの「更新してください」リンクは安易に押さない

---

### 困ったときは

- 画面に出ているエラーの文字を、そのままコピーして相談する
- 「いつから／何をした後か」をメモして相談する
- 直前の操作が原因のことが多い。迷ったらバックアップから戻す
- 手に負えないときは、契約しているサーバー会社のサポートへ
