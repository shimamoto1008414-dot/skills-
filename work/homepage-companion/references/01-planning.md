# ① 企画・構成フェーズ

ここはサイトの「設計図」を作る段階です。家を建てる前に間取りを決めるのと同じで、ここを一緒に丁寧にやると、後の制作がぐっと楽になります。初心者ほど早くページを作りたくなりますが、**先に「誰に・何を・どう伝えるか」を言葉にする**ことが、結局いちばんの近道だと伝えてください。

## このフェーズのゴール

終わったときに、次の3つが紙（テキスト）になっている状態にします。

1. **サイトの目的と相手**：このサイトで何を達成したいか、誰に見てほしいか
2. **サイトマップ（ページの一覧と構成）**：どんなページを、どんな順番で持つか
3. **各ページに載せる内容のメモ**：ページごとに何を書くか・何を載せるか

`assets/planning-sheet.md` が、お店・会社紹介サイト向けの企画シートのひな形です。これをユーザーと一緒に埋めていくのがおすすめです。

## 進め方：ヒアリング（聞き取り）

いきなり全部聞くと疲れさせてしまいます。会話しながら、少しずつ埋めていってください。1問ずつ、相手の答えに相づちを打ちながら進めるのがコツです。

### 聞くこと（お店・会社紹介サイトの場合）

**目的・ゴール**
- このホームページで、いちばん叶えたいことは何ですか？（例：来店を増やしたい／問い合わせがほしい／信頼してもらいたい／求人に応募してほしい）
- 見た人に最終的にどう動いてほしいですか？（電話する・予約する・地図を見て来店する・メールするなど）

**お店・会社のこと**
- 名前、業種、何をしているところか（一言で）
- 他のお店・会社と違う「ウリ」、こだわり、強み
- 創業の思いやストーリー（あれば。信頼につながります）

**見てほしい相手（ターゲット）**
- どんな人に来てほしいですか？（年代・地域・困りごとなど。「近所の30〜40代の家族連れ」のように具体的に）

**載せたい情報**
- 営業時間、定休日、住所、電話番号、地図、駐車場の有無
- メニュー／サービス／料金
- 写真（外観・内観・商品・スタッフなど。今あるか、これから撮るか）
- SNS（Instagram等）やネット予約はあるか

**好みのイメージ**
- 「こんな雰囲気にしたい」という参考サイトや、好きな色・トーン（明るい／落ち着いた／高級感／親しみやすい等）

> 💡 ユーザーが答えに詰まったら、選択肢を出してあげてください。「目的は、来店アップ／問い合わせ獲得／会社の信頼づくり、どれが一番近いですか？」のように。選択式の質問ツール（AskUserQuestion 等）が使える環境なら、それで選びやすくするのも有効です。

## サイトマップ（ページ構成）を一緒に決める

聞き取った内容から、必要なページを提案します。お店・会社紹介サイトの**定番の構成**は次のとおりです。これを土台に、過不足を相談してください。

| ページ | 役割 | 初心者へのひとこと |
| --- | --- | --- |
| トップページ（ホーム） | サイトの顔。一番見られる。要点と「次にどこを見ればいいか」を案内 | 必須。最初の印象が決まる場所 |
| 私たちについて／お店紹介 | 想い・こだわり・歴史。信頼をつくる | あると信頼感が出る |
| メニュー／サービス／商品 | 何を提供しているか、料金 | お店の「中身」。具体的に |
| アクセス・店舗情報 | 住所・地図・営業時間・電話・駐車場 | 来店してほしいなら必須 |
| お問い合わせ | フォーム・電話・メール | 「行動してもらう」ための出口 |
| （ブログ・お知らせ） | 最新情報・更新ネタ | 続けられそうなら。後から足してもOK |

**最初は欲張らないこと**を勧めてください。3〜5ページで小さく公開し、運用しながら育てる方が、初心者は挫折しません。「ブログは後からでも足せます」と伝えると安心します。

決まったサイトマップは、図にして見せると理解が早いです。簡単なツリー図（トップ → 各ページ）をプレビューで見せて確認すると親切です（出し方は SKILL.md の「プレビューの出し方」）。

## 各ページの中身メモ

ページごとに「載せる要素」を箇条書きにしておきます。例：

```
トップページ
- キャッチコピー（一番伝えたい一言）
- お店の写真（外観 or 看板メニュー）
- 3つの強み
- 各ページへの案内ボタン
- 営業時間・電話（すぐ分かる位置に）

アクセス
- 住所、Googleマップ
- 営業時間・定休日
- 電話番号
- 駐車場の案内
- 最寄り駅からの行き方
```

ここまで決まったら、企画フェーズは完了です。ユーザーに「設計図ができました。次は、これをインターネットに公開するための土台（サーバーなど）を用意します」と伝え、`references/02-setup.md` に進みます。

## このフェーズでのつまずき・声かけ

- **「何を書けばいいか分からない」** → 質問を細かくして引き出す。あなたが代わりに下書きを作って「これで合っていますか？」と確認する形にすると進みやすい。
- **完璧主義で止まってしまう** → 「公開後にいくらでも直せます。まずは8割で出しましょう」と背中を押す。
- **ページを増やしすぎる** → 「最初は小さく」を繰り返し勧める。
