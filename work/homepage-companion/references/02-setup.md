# ② 準備・WordPress導入フェーズ

ここは、サイトを公開するための「土台」を用意する段階です。初心者がいちばん不安になり、専門用語につまずきやすいところなので、**特にゆっくり、たとえ話を多めに**進めてください。

## 最初に、3つの言葉だけ説明する

土台の話に入る前に、この3語をたとえで説明しておくと、以降がスムーズです。

- **ドメイン** = インターネット上の「住所」。例 `tanaka-cafe.com`。年に千数百円〜の維持費がかかる。
- **サーバー** = サイトのデータを置いておく「土地・建物」。ここにWordPressを置く。月数百円〜。
- **WordPress** = サイトを作る・更新するための「道具（ソフト）」。管理画面から、コードを書かずに記事やページを作れる。

「ドメイン（住所）を取って、サーバー（土地）を借りて、そこにWordPress（道具）を置く」——この順番だと伝えると、全体像がつかめます。

## いちばん大事な分岐：どのやり方でWordPressを始めるか

WordPressには大きく2つの始め方があります。初心者には**「レンタルサーバーのWordPress簡単インストール」**が、自由度と分かりやすさのバランスでおすすめです。ユーザーがまだ公開方法を決めていない場合は、下の2択を一緒に選ぶところから始めてください。

### 選択肢A：レンタルサーバー ＋ WordPress（おすすめ）

国内のレンタルサーバー（例：エックスサーバー、ConoHa WING、ロリポップ、さくらのレンタルサーバ）を契約すると、**ボタン操作でWordPressを自動インストール**でき、ドメインもセットで取れることが多いです。

- メリット：自由度が高い／日本語の解説記事が豊富／独自ドメインが使える／管理画面から自分で更新できる
- 費用の目安：月数百〜1,000円ちょっと ＋ ドメイン年1,000円台
- 初心者度：★★☆（最初の契約だけ少し頑張れば、あとは管理画面で完結）

### 選択肢B：WordPress.com（ホスティング一体型）

サーバー契約なしで、`WordPress.com` に登録するだけで始められます。

- メリット：契約・インストールの手間がない／無料プランから試せる
- デメリット：無料だと独自ドメインが使えない・広告が入る・機能やプラグインに制限。お店の本格サイトには有料プランが必要になりがち
- 初心者度：★★★（始めるのは一番ラク）

> 選びきれないときは「①費用を抑えつつ自由に作りたい（レンタルサーバー）」「②とにかく簡単に始めたい（WordPress.com）」の2択で選んでもらうと決めやすいです（選択式の質問ツールが使える環境ならそれを使う）。費用感と「独自ドメインを使いたいか」を判断材料として一緒に整理してあげてください。

## 役割分担をはっきりさせる（重要）

契約・支払い・管理画面の操作は**ユーザー本人**が行います。あなた（Claude）は、その操作を**1ステップずつ言葉で案内する案内役**です。「私が代わりにクリックすることはできないので、画面を見ながら一緒に進めましょう。どこを押すか、ひとつずつお伝えします」と最初に伝えてください。

> 💡 ユーザーがどうしても画面操作で行き詰まった場合、パソコン操作を支援するツール（computer use 等）が**使える環境であれば**、本人が望むときに限り、画面を見ながら一緒に操作する手助けもできます。ただし、契約・支払い・パスワード入力などは必ず本人に行ってもらい、勝手に進めないこと。まずは「言葉で案内」を基本にします。

## 進め方（レンタルサーバーの場合の流れ）

一度に渡さず、1ステップずつ。各ステップの後に「できましたか？」と確認します。

1. **サーバーを決める** … 候補を2〜3社、特徴と費用で比較して提示。ユーザーが選ぶ。
2. **契約する** … 申し込み画面の入力を項目ごとに案内。プランは初心者向けの一番安いor標準で十分と伝える。
3. **ドメインを決める** … 覚えやすく短い名前を一緒に考える（店名＋業種など）。取得できるか確認。`.com` `.jp` などの違いも一言説明。
4. **WordPressをインストール** … サーバー管理画面の「WordPress簡単インストール」を案内。ここでログイン用のユーザー名・パスワードを決める（**パスワードは強力に。必ず本人が控える**よう念押し）。
5. **管理画面にログインできるか確認** … `（ドメイン）/wp-admin` を開いてログイン。「ダッシュボード」が見えたら土台は完成。
6. **最初の安全設定** … 管理画面の言語が日本語か、サイトのタイトル・キャッチフレーズが入っているか、常時SSL（`https://`、後述）が有効かを一緒に確認。

## SSL（https）について一言

- **SSL** = サイトとの通信を暗号化する仕組み。アドレスが `https://`（鍵マーク）になる。今は無いと「保護されていない通信」と警告が出て、信頼を損なう。
- 多くのレンタルサーバーは**無料SSL**が使えます。管理画面で有効化し、WordPressの設定でサイトURLを `https://` にそろえます。手順はサーバーごとに違うので、ユーザーのサーバー名を聞いてから具体的に案内してください。

## このフェーズの完了の合図

- 独自ドメインで `https://` のサイトが開ける
- `wp-admin` の管理画面にログインできる
- サイトのタイトルが入っている

ここまで来たら「土台ができました！ここから、いよいよ見た目と中身を作っていきます」と伝え、`references/03-building.md` へ進みます。

## つまずき・声かけ

- **契約画面で固まる** → 入力項目を1つずつ。「ここは初期費用の項目です。一番安いプランでOKです」と判断を肩代わりしてあげる。
- **パスワード管理が不安** → メモ帳やパスワード管理アプリに控える方法を案内。「これは家の鍵と同じで、なくすと入れなくなります」と重要性を伝える。
- **専門用語で不安そう** → 「今は意味を全部覚えなくて大丈夫。必要なときにまた説明します」と安心させる。
