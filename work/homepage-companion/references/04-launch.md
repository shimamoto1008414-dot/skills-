# ④ 公開フェーズ

いよいよインターネットに公開します。初心者にとっては緊張する瞬間ですが、「公開後もいくらでも直せる」ので大丈夫だと先に伝えてください。ここでは、慌てて公開ボタンを押す前に、一緒に**最終チェック**をします。

## 公開前チェックリスト

ユーザーと一緒に、上から順に確認します。一度に全部見せず、項目ごとに「ここは大丈夫ですか？」と進めると親切です。サブエージェントに「実際のサイトを点検して、崩れ・リンク切れ・誤字を報告して」と頼んで、機械的なミスを拾うのも有効です。

### 内容
- [ ] 店名・会社名の表記が正しい（よくある誤字に注意）
- [ ] 住所・電話番号・営業時間・定休日が正確（**間違えると実害が出る最重要項目**。本人に再確認してもらう）
- [ ] 料金・メニューが最新
- [ ] 誤字脱字がない
- [ ] 問い合わせ先（フォーム・電話・メール）が正しく、実際に届くか

### 見た目・表示
- [ ] **スマホで見て**崩れていない・読みやすい（多くの人はスマホで見る）
- [ ] パソコンでも崩れていない
- [ ] 写真がきれいに表示され、重すぎない（表示が遅くないか）
- [ ] リンク・ボタンがすべて正しく動く（リンク切れがない）
- [ ] メニューから全ページにたどり着ける

### 技術・信頼まわり
- [ ] `https://`（鍵マーク）で表示される（SSLが有効）
- [ ] サイトのタイトルと説明（検索結果に出る文章）が設定されている
- [ ] 不要な初期データ（WordPressの「Hello world!」サンプル記事・サンプル固定ページ）が消えている
- [ ] ファビコン（ブラウザのタブに出る小さなアイコン）が設定されている（あると本格的に見える）
- [ ] 問い合わせフォームを使うなら、テスト送信して受信できるか確認
- [ ] 問い合わせフォームで名前・連絡先など個人情報を受け取るなら、**プライバシーポリシー（個人情報の取り扱い）ページ**があり、フォームの近くからたどれる（日本のサイトでは定番。ひな形はあなたが下書きしてよいが、内容は事業者本人に確認してもらう）

### 公開設定（重要）
- WordPressには「**検索エンジンでの表示を許可しない**」というチェックがあります（設定 → 表示設定）。制作中はオンでもよいですが、**公開時は必ずオフ**にしないと、Googleなどに載らず誰にも見つけてもらえません。ここは見落としやすいので必ず一緒に確認してください。

## 公開する

レンタルサーバー＋独自ドメインで作っている場合、多くは「制作中もそのURLで見えている」状態です。その場合の「公開」とは、上のチェックを終えて、検索エンジンに見つけてもらえるようにし、関係者に告知することを指します。

- 検索エンジンの表示を許可（上記チェックを外す）
- メニューや内部リンクを最終確認
- 公開を周知（名刺・SNS・店頭・Googleビジネスプロフィールなど）

> 別の場所で作って本番に移す「引っ越し型」の場合は構成が変わります。ユーザーの状況（本番ドメインで直接作ったか、テスト環境で作ったか）を確認してから具体的に案内してください。

## 公開直後にやっておくと良いこと

- **Googleビジネスプロフィール**（無料）に登録すると、店名で検索したとき地図や情報が出やすくなる。お店なら特に効果が大きいので案内するとよい。
- **Googleサーチコンソール**にサイトを登録すると、検索での見え方が分かる。余力があれば。
- 公開のお祝いを一言。「おめでとうございます！世界中から見られるサイトになりました」——初めての公開は大きな達成です。ねぎらってください。

## 完了の合図と次の案内

公開できたら、ここで終わりではないことを伝えます。「これからは、サイトを健康に保つ『保守』と、育てていく『改修』のフェーズです。難しくないので、続けていきましょう」と声をかけ、`references/05-maintenance.md`（保守）の習慣づくりへ案内します。特に**バックアップの設定は公開直後にやっておく**と安心だと勧めてください。
